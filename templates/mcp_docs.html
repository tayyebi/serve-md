Model Context Protocol

This serve-md server (v{{version}}) exposes the documents it serves to AI agents over the Model Context Protocol, at POST /mcp. This page documents that endpoint.

Calling the endpoint

The endpoint speaks JSON-RPC 2.0 over Streamable HTTP. One POST carries one request and returns one JSON response. There is no session and no handshake:

POST /mcp
Content-Type: application/json

{ "jsonrpc": "2.0", "id": 1, "method": "tools/list" }

Supported methods:

  • server/discover — capabilities up front (protocol {{protocol}})
  • tools/list — the tools below
  • tools/call — run one of the tools
  • resources/list and resources/read — browse documents
  • ping — liveness

Resources

Every document is also published as an MCP resource with the URI scheme serve-md:///<path>, so clients can attach one directly without calling a tool.

Also available

Agents and people can discover this server through:

  • /.well-known/mcp.json — the MCP server card
  • /llms.txt and /llms-full.txt — the llms.txt index
